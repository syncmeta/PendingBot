# 头像 / 昵称可见性

头像和昵称**不全局公开**。核心权威 = 决策 D3。这是贯穿 [加好友](../../pendingbot/features/add-friend.md) 和群成员路径的一条隐私底线。

**逻辑** — 只有两个合法暴露场景,各自从不同来源拿对方信息:
1. **加好友时** —— 经 handle 查找,看到对方头像 + 昵称(否则没法确认是谁)。
2. **群聊里** —— 看到非好友群成员的头像 + 昵称(否则群里全是匿名 id)。

除这两处,**没有需要公开头像 / 昵称的地方,就不公开**。

**为什么** — 党纲"隐私默认收紧"的具体落点:头像不是全局公开资源。两条路径都只在"对方已经把自己暴露给这个上下文"(挂了隐私号 / 同在一个群)时才给信息,且只给**显示所需**——头像图片字节 + 昵称,不给文件元数据(`r2_key` 等)。

**用在哪·长什么样** — 你不会在任何"陌生人列表"里看到别人的头像;只有当你查某人的隐私号、或和某人同群时,才渲染得出对方的脸和名字。手段是 **id-as-capability**:头像 attachment 的 id 不可枚举、只能从合法处(查找结果 / 群成员列表)拿到,凭它取到的也只是图片字节。

**边界 / 注意**
- 这是**头像可见性的产品底线**,加好友和群成员路径都受它约束。
- 不公开 = 没有第三条暴露路径;新增任何"想看到别人头像"的需求,要么归到这两条、要么明确拒绝。
