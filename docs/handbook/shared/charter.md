# 党纲与准则

> 大绿豆的不可谈判信条。任何新决策与这里冲突,要么改决策、要么改这份。
> 工程的机械约定(分支模型 / commit / 迁移 / 部署 / 四账本纪律)见根 [`CLAUDE.md`](../../../CLAUDE.md),不在此重抄。

## 产品信条

- **是朋友,不是助手** — "朋友"不是说它像人(不拟人),是说它给你**真价值**:会指出你的错、给你新视角、不谄媚,而不是一个有求必应、只会附和的工具。两件核心(复盘 / 校正、网上冲浪)都不用催、到点自己做。
- **知错为核,主动为辅(已降级)** — 产品的内核是**"知道自己错了的 AI"**:lookback / 复盘就是为这个设计的——能回看、能承认自己之前判断错了、能自我校正。知错比主动更根本,是主动的前提(不知错的主动只是添乱)。**主动性已降级**:它不再是内核 / 灵魂、也不再是筛选新功能的尺子,只是 PendingBot 一个(后来弱化的)差异化特质。加新能力先问的是:它能不能让 bot 更会知错、自我校正。
- **社交建立在信任上,不做开放广场** — bot 和群都是邀请制 + 留痕,不做陌生人可搜的公开身份;隐私默认收紧(头像 / 昵称只在"加好友"和"群成员"两条路径暴露)。
- **两个产品,像微信 / 企业微信** — PendingBot 是普通人的日常入口(三端 IM),PendingCrew 是开发者的 crew 编排台(可开源)。两者**相互隔离、解决不同问题 / 场景,没有共享母题**:PendingBot 的人和 bot 能无缝参与进 PendingCrew,但功能各管各的。PendingBot 看见 crew、PendingCrew 深度操作 crew,互不吞功能。("人与 AI 协作"是 PendingCrew 自己的说法,不是两产品共享的母题。)
- **对标 ≠ 类比,大绿豆 sui generis(无可对标)** — 大绿豆从不对标任何现有产品;**能被对标 = 已经有人做了 = 做它就没意义**。文档里的类比(如"像 ChatGPT / Claude 的 iOS app 那一档")只为帮人理解形态,绝不是竞争标的——写定位永远不写"对标 X / 竞品 / 像 X 但更好"。这条与商业立场的"不重复造轮子"是一对、不矛盾:**基础设施 / 商品层用成熟方案别造轮子,产品本身做没人做过的事(无可对标)**。

## 红线

- **配置走 board / 前端,不硬编码** — 模型 slug、功能开关、运营文案这类该可改的,一律进 board / KV,不写死在代码。
- **给 LLM 的文本走 prompt 通道** — 所有 prompt 走 `prompts/<locale>/*.md` + loader / Langfuse,不内联成 const 字符串。
- **不为图省事埋雷** — 任何绕过当下约束的临时方案(关签名 / placeholder / 双写 / 只验最易过的路径)必须立刻记 tech-debt 或加 fail-loud 校验;验证要覆盖**最终使用路径**(真机),不是只验最容易过的那条。
- **已落地 = 已验证,不是"代码写完"** — `completed` / ✅ 以"验过可用"为准。
- **优先原生、优先长期体验** — 能用原生组件就不自绘;默认不推"省事最快",要最优体验。

## 商业立场

- **不重复造轮子,不碰技术红海,用成熟方案** — 除非我们特别有优势能做得更好,否则一律用现成的成熟产品 / 方案 / 思路 / 研究;不碰纯技术红海(任务路由、算法这类——很多人在做、且难),等别人研究透,尽早发现、采纳。我们的分工是**专注应用搭建与设计**(我们的优势),底层工程交给专业的人。下面这一连串外包决策(CF AI Gateway 统一计费、Polar + RevenueCat、不直连 Stripe、Grafana / PostHog / Langfuse / Sentry、CF Container 群语音、不自建 board)都是**这同一条总原则**的展开。
- **未发布,单环境** — v1 没发,只有一个 Supabase + 一个 prod worker;不搞 staging / 多环境基建。
- **不在中国大陆上架** — 中文只是开发语言,评估时别把中国 App Store 限制当约束。
- **关键基础设施外包,零 VPS** — 模型走 Cloudflare AI Gateway 统一计费(OpenRouter 留 fallback);计费引擎 Polar(MoR)+ RevenueCat,门禁走 WalletDO,不直连 Stripe;观测用 Grafana / PostHog / Langfuse / Sentry。
- **域名 `pendingname.com`** — 邮件 / Site URL / Universal Link 都基于它;对外品牌站在另一个仓库。
