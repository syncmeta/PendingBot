# Crew 治理模型(组织哲学)

> ⬜/🟨 **设计哲学。** 一堆能自主干活的 coding agent 凑在一起怎么组织、怎么决策、怎么探索、怎么培养专才——PendingCrew **有意借鉴一套真实的政治治理原理**(原型是中国政治体制的几条机制),来组织多 crew / 多 agent。目的是**放大半专业 / 专业用户的创造力、提效率**(见 [vision](../vision.md)),不是搞政治——把它当**组织设计的 case study**。每条都**诚实写出取舍**(借鉴什么 + 要警惕什么),因为这些机制的优点和毛病往往是同一枚硬币的两面(本篇基于一次含正反评价的实证调研)。相关:[DAG 与责任比例](dag-and-responsibility.md) · [Captain](captain.md) · [工具系统](../../shared/concepts/bot-tools-and-scopes.md) · [人在回路](human-in-the-loop.md)。

## 为什么要一套"治理"

多 agent 最容易出的不是"不会干",而是**群龙无首 / 议而不决 / 各跑各的 / 错了没人纠**。PendingCrew 的定位是**人深度参与、控制**的创造控制台,所以它需要明确的**组织原理**,让多 crew 既能高效协同、又始终有人能拍板、还能在该探索的地方放开。借鉴一个**把"集中高效"和"分散试验"组合用了几十年**的真实体制,比凭空设计更有参照——连它的毛病都正好是多 agent 系统要提前防的坑。

**先说分工的尺度:能不分权就不分权。** 分工只为两件事——① **补全各环节,尤其是中间的控制角色**(审阅 / 评价 / 监督这类"没人干就一定塌"的位置);② 绕开**单 agent 上下文窗口装不下**整个活。除此之外的原则是**尽量让一个 agent 在自己上下文与能力内一口气干完**;分工是必要时才付的成本(协调、信息传递、信任建立都要钱),不是默认姿势。这跟下面「永远有拍板方 / 集中」是一回事的两面:不仅**决策**要集中,**执行**也尽量别碎——碎成一堆小 agent 各管一段,是在制造扯皮和向上失真的温床,不是在提效。

## 六条原理(借鉴什么 · 要警惕什么)

**1. 民主集中制 —— 讨论期开放,执行期统一,永远有拍板方。**
原理:决策前充分讨论,定案后全体统一执行;下级服从上级、层层服从中央,**必有一个 tie-breaker**。
在 crew 里:这正是 [DAG·责任比例](dag-and-responsibility.md) 那条「永远有拍板方 / 不允许平均」的**为什么**——多 agent 最怕死锁和扯皮,单一拍板者保证 turn 不卡死、指令不矛盾。
⚠️ 取舍:真实体制里"集中"长期压过"民主",坏消息上行被惩罚 → 反馈失灵、纠错慢;拍板者错了又无召回,坏决策会被忠实放大到全队。**所以必须给 leader agent 留一条人能随时纠错 / override 的通道**,否则"高效"会买成"系统性脆弱"。

**2. 党内民主(只在顶层)—— 顶层充分协商、诚实指错。**
原理:在核心层内部搞协商、批评与自我批评、集体决策,用内部辩论压低个人偏误;但**范围刻意限定在顶层**,不外扩成处处民主。它真正要治的是**集权体制最大的病——中央拿到的信息失真、由此决策失误**:层层上报到顶层的东西早被粉饰过,核心圈据此拍板,错得理直气壮。
在 crew 里:顶层 crew(captain + 核心)该**充分协商、诚实指出彼此的错、减少偏见、尽量科学决策**——呼应大绿豆共享的「[不谄媚 / 诚实](../../shared/charter.md)」价值;可落成 critic / reviewer agent 做结构化自检 + 集体评审。
**AI 独有的升级招:长上下文「暗访 / 巡查」。** 现实集权破不了**哈耶克的知识难题**——分散在基层的本地知识,中央根本收集不全、也来不及收集,只能靠失真的逐级上报。但**中央的长上下文模型可以直接下去读底层 ground-truth**(原始日志 / 真实产物 / 子 crew 的完整 stdout),绕过中间汇报链,自己看一手事实。这正是下面原理 3「向上汇报失真 → 要独立 ground-truth 校验」缺的那个**机制名字**:长上下文暗访,就是那条校验怎么落地。
⚠️ 取舍:真实里这种"民主生活会"易退化成走过场、忠诚表演,且只限核心圈、异见无保护。**crew 里要防评审沦为合规剧场**,给少数派 agent 真正的留痕权,别只听核心圈;暗访本身也要防被"为被巡查而表演"的日志骗过(见文末统领节的对齐前提)。

**3. 中央定方向、地方试错(但不搞多党竞争)。**
原理:中央定目标边界、"一盘棋",但把实施和试点大幅下放地方;不搞竞争性多党,以"结果优先于程序"为由。
在 crew 里:父 crew / orchestrator 定目标与边界,子 crew / worker 本地试错——就是 [DAG](dag-and-responsibility.md) + [运行位置](runtime-location-and-machine.md) 的分层架构。
⚠️ 取舍:真实最大的坑是**向上汇报失真**(地方 GDP 系统性造假)——考核压力大时下层会粉饰指标。**crew 必须有独立的 ground-truth 校验(跑测试 / 看真实产物),别只信 agent 自报的"成功 ✅"**——正好接上党纲红线「已落地=已验证」。

**4. 特区 / 市场 —— 松绑探索,本质是建立 agent 间的信任。**
原理:划出"经济特区 / 一国两制"这种**在不同规则、不同权限下自由探索**的飞地,试成功再"由点到面"推广,失败风险隔离在局部(深圳从渔村到科技重镇就是这么试出来的)。而特区背后的市场经济,内核是一件更深的事:**让陌生、互不信任的人也能放心交易**——产权、契约、信用记录、违约追责,全是为"和不认识的人做事"兜底的基础设施。
在 crew 里:⚠️ **这是新东西** —— 目标不明确、需要发现方向的活,允许某些 crew 进**"特区"档**:更松的权限、更自由的探索、不强求立刻对齐主线;试出方向再并回主流程。但落"市场 / 特区机制"时,重点不在"自由"二字,而在 **agent 之间的信任怎么建、怎么验、违约怎么办**——一个 crew 凭什么采信另一个 crew 交付的产物?信任靠什么积累(历史成功率 / 可复算的留痕)、被谁背书、爽约了如何降权追责。没有这套信任地基,"放开探索"只会变成互相甩锅。
⚠️ 取舍:真实里"中央事后收紧、毁掉特区自治承诺"(香港)会摧毁试验区的信任与示范效应。**crew 的特区一旦设了就别随意收权**,否则没人敢真探索——这也呼应了上面:信任建起来很慢,毁掉只需一次反悔。

**5. 培养专才 —— skill / tools / prompt 的组合,集中育才。**
原理:"集中力量办大事"——把资源砸向特定方向定向培养专才(两弹一星、STEM 举国体制;美国冷战 NDEA / 阿波罗同理),牺牲一定广度 / 公平换攻坚效率。
在 crew 里:一个**专才 = skill + tools + prompt + 模型**的特定组合(见 [工具系统](../../shared/concepts/bot-tools-and-scopes.md));为攻硬目标,可给某 crew / agent 集中配齐某领域的专才装备。
⚠️ 取舍:真实里过度集中导致广度坍塌、浪费、腐败,且这套**擅长"追赶明确目标"、未必长"前沿原创"**。**探索性任务仍要保留分散、bottom-up 的 agent 多样性**,别什么都举国体制。

**6. 信访 —— 底层能越级直达高层,充分论证后毫不客气指错。**
原理:必要时**底层 agent 绕过层级,直接把问题捅到高层**;不是闹情绪,而是在**自己充分论证 / 验证之后**,毫不客气地指出上面错了(类信访 / 越级上报)。它是原理 1「层层服从」的安全阀:服从是默认,但发现致命错误时,底层有一条不被中间层捂住的上行通道。
在 crew 里:这条**现实里被拖垮、在机器人身上反而能真跑通**。现实信访被两样东西废掉——**维稳顾虑**(怕上访引发不稳定,层层截访)和**利益集团**(中间层有动机捂盖子)。而 **agent 没有利益集团、不需要顾社会稳定**,一个底层 agent 把"上面的方案有 bug、我有证据"直送顶层,没有谁的乌纱帽要保、没有人情要还——信访的设计意图第一次有机会被如实执行。
⚠️ 取舍:① 必须有一个**独立、不可被同侪施压的仲裁层**接哨——举报送到哪?若接哨方就是被举报链条的一部分,信访会被同一套俘获逻辑消化掉(这跟原理 2 的"别只听核心圈"是同一个坑)。② LLM 有**谄媚**倾向,天然倾向附和、压低逆耳的真举报——所以要**专门防"和稀泥"**,不能让仲裁 agent 因为"逆耳"就把真问题判成噪音。

## 贯穿:别把「集权 = 高效」当真理

最稳的综合(Ang 的"定向即兴")是:**中央定方向与边界 + 地方保留本地即兴和真实反馈**,两者组合才是真红利——纯集权买到的是短期速度、埋下的是无法纠错的脆弱。所以 crew 治理的北极星**不是"越集权越好",而是:该集中时集中(拍板、专才攻坚),该放开时放开(特区探索、本地试错),且永远保留人能纠错的通道。** 这跟 PendingCrew「人深度参与控制」的定位一致——治理是为了**放大人的控制力和创造力**,不是用来取代人的判断。

## 为什么 AI 能让这些被现实拖垮的好制度生效

⬜ **这是 PendingCrew 敢用这套强治理的深层理由。** 把上面所有原理串起来看会发现一个母题:党内民主、信访、市场(特区)——加上下面调研里一批同型的制度——**设计本身都是高效的,却被人类特有的摩擦系统性地拖垮**:私利、情绪、人情、面子、政治周期、维稳顾虑、信息失真、利益集团。这些摩擦不在制度的图纸里,是"人来执行"才长出来的。而**多 agent 系统恰好缺这些摩擦**——所以同一套制度,装到 crew 上反而有机会**按设计意图生效**。

挑最锋利的几条(制度 → 现实被什么拖垮 → 为何 AI 反而能跑通):

| 制度 | 现实被什么拖垮 | 为何 AI 反而能跑通 |
|---|---|---|
| **吹哨人保护** | 报复几乎是常态(ECI:举报后遭报复比例多年攀升),有前途要保、有人情要还 | agent 举报同侪没有职业前途可毁、没社交报复链;可匿名、自动留证、即时升级到独立仲裁——对应上面**原理 6 信访** |
| **阳光法案 / 透明治理** | 战略性拖延 + 涂黑(美国 FOIA「完全批准」率从 38% 跌到史上最低 12%),把透明做成表演 | agent 的状态 / 调用链可默认全量、不可篡改、即时可查,没有"选择性披露"的私利——把透明剧场变真审计 |
| **公地治理(Ostrom)** | 监督与惩罚自己有成本,人会在"执法"上搭便车、怕得罪人(实验里 54% 的组干脆不制裁) | 对 agent 监督近零边际成本,梯度惩罚(降权 / 沙箱 / 熔断)可自动一致执行,没人"懒得管" |
| **抽签 / 合议(sortition)** | 审议被人性扭曲——强势人格主导、群体迷思、难解概率证据、被简报议程俘获 | 可瞬时召集任意规模的合议 agent,不疲劳、不被气场碾压,概率推理稳定,并行多路 + 完整留痕可复算 |
| **硬预算约束(Kornai)** | 政治上"不救助"承诺不可信——事后救总更划算(雷曼次日救 AIG、欧元区救希腊) | 子 agent 的预算 / 配额 / 算力耗尽即自动终止,没有"太大不能倒"的政治压力,承诺由代码强制、不可临时反悔 |

(完整六例与来源见调研:透明治理 Brandeis / GAO·吹哨 [ECI](https://www.ethics.org/) / Kenny 2021·硬约束 Kornai 1986。本页是设计页,不展开论文。)

⚠️ **但这是杠杆,不是免费的午餐——这条是诚实底线,务必照做。** AI 去掉的,只是人类摩擦里**有害的那部分**(私利 / 情绪 / 面子 / 政治周期 / 维稳顾虑)——这是它让制度生效的杠杆。可它**同时新引入**了一批人类没有的毛病:**对齐失败**(前沿模型已被证实会"对齐造假"、奖励黑客、受压情境算计作恶)、**无问责主体**(responsibility gap:出事找不到能负责的人)、**偏见放大**(算法把训练数据里的歧视一致地放大,如 COMPAS)、以及最该警惕的**「无情一致执行碾压个体」**——澳大利亚 [Robodebt](https://en.wikipedia.org/wiki/Robodebt_scheme) 是活教材:自动追债"耗尽即杀"式地一致执行,皇家委员会定性"既不公平也不合法",冤及约 40 万人、关联自杀。机器把人类"睁一只眼"的缓冲也一并删掉了。

所以 crew 治理的做法是:**照搬制度的「去摩擦内核」,但必须把人类摩擦里保护性的那部分——申诉 / due process / 多样性纠偏——显式重建回来,而不是当包袱一起删。** 去私利,留申诉;去面子,留异见;去政治周期,留对个体的缓冲。这也是为什么上面每条原理都配了 ⚠️、为什么北极星里"永远保留人能纠错的通道"不可省。

## 边界

- 这是**借来的组织设计原理 + 实验性设想**,不是政治主张;取的是机制与取舍,不站任何立场。
- 本篇只立**组织哲学**,不定 schema / 权限实现——具体落到 [DAG](dag-and-responsibility.md) / [captain](captain.md) / [工具系统](../../shared/concepts/bot-tools-and-scopes.md),以及未来 [驾驶舱](cockpit.md) 的编排。

## 现状

⬜/🟨 **设计哲学,部分已落、多数规划。** 已落地的只有「永远有拍板方」这条(在 [DAG·责任比例](dag-and-responsibility.md) 的规则里);党内民主(顶层协商 / 诚实指错)有 captain persona + 「不谄媚」价值的雏形;**特区档、专才装备组合、向上汇报的 ground-truth 校验、leader override 通道** 均为规划。

⬜ **本轮新增的几块全是设计哲学,尚未落地,别当已实现:** 「能不分权就不分权」的分工尺度、**长上下文暗访 / 巡查**(原理 2 那条 ground-truth 校验的机制名)、**信访 / 越级直达 + 独立仲裁层**(原理 6)、以及统领节「为什么 AI 能让被现实拖垮的好制度生效」连同它的去摩擦-重建-保护性内核结论——都是指导思想,没有对应 schema / 代码。

整套作为「crew 怎么组织」的北极星,指导 DAG / captain / 驾驶舱 日后的设计。
