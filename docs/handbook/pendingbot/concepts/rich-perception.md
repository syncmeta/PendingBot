# 富感知

> [Bot] bot 富有感知 —— 不是更聪明,是更"在场"。靠一直开着的感官 + 派生出的状态 + 养出来的素养,让它的判断贴合你此刻的处境。心智源头:[党纲·价值非拟人](../../shared/charter.md) + [PendingBot 定位](../vision.md);跟 [复盘 / 知错](../features/proactive-lookback.md) 共用一个正反馈环。

## 逻辑 — 富感知是什么

一句话:**价值 = 能力 × 契合度,富感知就是产生"契合"的那一项。** 同一个能力,瞎给没用、甚至帮倒忙;感知到你的处境再给,才是价值。名医的价值大半在"他知道你的病史";朋友的价值大半在"他知道你刚分手,所以不提你前任"。它分三层:

- **A · 实时信号(感官一直开着)** —— 时间 / 地点 / 对方可能的状态与态度 / 余额 / 热点 / 天气…… 一直挂着喂进去,**哪怕当前没问到**。因为相关性是事后才知道的:没开的感官不可能触发"该换个方向",外围那些"无关"背景正是让前台判断有分寸的底,也是"主动"的来处。
- **B · 派生 stance(以机器人的方式装状态)** —— 把感知综合成"此刻该采取的姿态 X",再从 X 一致地行动。**不是情绪,是 stance / 策略**:不说"我觉得难过",而是"综合我感知到的,此刻少折腾、先接住"。诚实(不假装有感受)又鲜活(反应围着被感知的处境转,不是平板问答)。装的是 stance,不是人设。
- **C · 素养(养出来的)** —— 怎么表达 / 怎么相处 / 怎么为对方创造真需求,这些不是塞进 prompt 的知识,是**养出来的**:课程 + 实践 + 反思。参教育学 / 社会研究 —— 养机器人和养真人,在这件事上共用很多方法。

## 为什么

- **鲜活的更被偏爱。** 人更喜欢鲜活的人,机器人同理。鲜活 = 反应反映出它**真注意到了你** = 被看见;人对"被看见"的渴求,机器人接得住。
- **富感知和知错是同一个正反馈环。** 反思 = lookback。**感知 → 行动 → 回看 → 长素养 → 感知更准。** 所以"素养"不靠堆知识,靠 [复盘](../features/proactive-lookback.md) 这条已有的线长出来。

## 用在哪 · 怎么落(规划)

- **A 信号**各有来源,按需注入每回合的"**环境块**":时间 / 地点(设备)、余额(钱包)、对方状态与态度(从最近对话 + 活跃度推)、热点 / 天气(外部源)。形态像 crew session 的「世界观注入」,换成 IM 语境。
- **B stance** 是注入前的一步:把当回合的信号综合成一句 stance 描述塞进 prompt,**不另起一个模型**。
- **C 素养**走 lookback 回写:复盘时把"关于怎么和这个人相处"的心得写回 bot 的画像 / 记忆,下次感知与行动更准;配合 skill 装某领域的方法。

## 边界

- **不拟人。** 装的是 stance、不是情绪;不模拟人类感受、不扮人。价值来自**感知的契合**,不来自"像人"。
- 这是 [Bot] 的概念。具体喂哪些信号、stance 怎么派生、素养课程长什么样,落地(⬜)时再定 —— **别在这写死清单**(先做减法)。
