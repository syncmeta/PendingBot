# 主动复盘 · 校正

每聊上一阵,bot 自己回头**重看你俩的对话**:核查谁说糊涂了、指出你可能有的盲区,攒成一条只给它自己看的笔记,再在下一轮自然地带回来跟你讲。不用你催、到点自己做——这是大绿豆三件核心主动能力之一。相关:[主动性](../concepts/proactivity.md) · [来信](envelope-inbox.md) · [网上冲浪](web-surf.md)。

**逻辑**

- **每聊 N 轮,触发一次回看**。N 是每个 bot 可调的节奏(默认每 10 轮),计数是按 **(bot, 用户)** 累计的,**跨会话**——你和同一个 bot 在不同会话里聊的轮数会累加,到点就回看。
- **回看 = bot 重放最近的对话,做一次自省 + 查证**。它读最近一段聊天记录,被要求核查"我哪说糊涂 / 说错了、你哪有盲区或没说清的地方",然后写一条简短笔记。
- **笔记是写给未来的自己看的,对你不可见**。它落进 bot 的私有笔记区,不是一条聊天消息。下一轮 bot 给你回话时,这条笔记会进入它的思考上下文,让它在回复里**自然地**把复盘 / 校正的内容讲出来——不是生硬地"我刚才复盘了一下",而是顺着对话带出新角度。
- **没东西可说就闭嘴**。如果这次回看没发现值得讲的,bot 输出一个静默标记,这次**不留任何笔记**——宁可不说,不凑废话。
- **避免重复**:还"活着"的旧笔记会一并喂给回看,让 bot 别把已经提过的点再记一遍。
- **讲完即弃**:bot 在后续某轮回复里觉得某条笔记的使命完成了,可以主动把它标记为失效(`[DROP_LOOKBACK]`),笔记退场;否则它一直挂着、持续影响后面的回复。
- **能手动催一次**:你也能在会话里手动触发一次回看(对应"复盘"入口),手动触发会顺手重置自动计数,免得紧接着又自动来一遍。

**为什么** — bot 是"会反驳你、给你新视角的朋友",不是听话的工具。被动应答的 bot 永远只回答你问的;主动复盘让它**回头审视**——发现自己上一轮其实没讲清、或者你有个没意识到的盲区,主动补回来。把"自省"和"指出你的盲区"做成到点自动发生的事,是党纲"主动性是内核"的直接落地。

**用在哪·长什么样**

- **对用户基本是隐形的**。你不会看到那条笔记,也不会看到"bot 正在复盘"的过程;你感受到的是:聊着聊着,bot 时不时回头补一句更深的观察,或纠正一个之前没说准的地方。
- **手动入口**:会话里有"复盘"动作可手动触发一次,触发后约 30 秒(若你没继续发消息)bot 会自动接着上一轮、带着复盘结论往下说。
- **节奏可配**:每个 bot 的设置里能开关复盘、调每隔多少轮一次。

**示例** — 你跟一个 bot 连着聊了十来轮选笔记本电脑。到点它自己回看了这段对话,意识到:① 它前面把某个型号的续航说得太绝对了;② 你一直在纠结性能,但从没提过预算,这是个盲区。它记下这条笔记。你下一句刚发出去,它的回复里就自然带出来:"对了,前面续航那块我说得太满,实际看场景;另外你还没说预算区间——这其实最影响选型,要不先框个数?"你没催,它自己回头把对话校正了。

**边界**

- **笔记不是聊天消息**,你看不到它的原文;它只活在 bot 的上下文里,通过影响下一轮回复间接对你可见。
- **不强行产出**。素材不够(对话太短)或没发现值得说的,这次回看不留笔记、悄无声息。
- **目前是"由聊天驱动"的,不是真正的定时后台任务**。计数靠你和 bot 聊天累加,到阈值才触发;没有独立的 cron 在你完全不聊的时候也回看(见注意)。

**注意**

- **机制换过、行为对齐旧版**:复盘脱胎自早期的"自动 review",触发节奏(每 N 轮)沿用旧的 auto-review 旋钮,但**机制完全不同**——旧版是直接给你产出一段评价,现版是 bot 给未来的自己写私有笔记、再自然融进下一轮回复。别把它当成"会冒出一条系统点评"的旧形态。
- **"到点自己做"目前的"点"是聊天轮次,不是钟表时间**。党纲说三件核心能力"到点自己做",复盘的"到点"= 聊够 N 轮;真·定时(比如你三天没聊它也主动回看)还不是现状。
- **跨会话累计**容易让人误以为是按单会话算——计数键是 (bot, 用户),你和这个 bot 在哪个会话聊都算进同一个计数器,但回看时取的是**当前会话**最新的对话记录。

**现状** — 🟨 代码已落、已部署(`runLookback` 在 prod worker:自动节奏 + 手动触发端点 + 笔记经实时通道推给客户端 + 下一轮自动接话)。主路径在线上跑过。**尾巴**:复盘指令 prompt 早期有一处漏迁 Langfuse(`LOOKBACK_INSTRUCTION`,已记审计),以及端到端真机视觉验证(手动触发 → 30s 自动接话 → 复盘内容自然出现)尚未单独留证。
