# 模型盲盒(Model Blind Box)

会话里抽一个模型、藏起真名叫 **PendingModel**,让你猜是哪个模型;猜中或放弃才揭晓。是把「模型选择」从一件功能性的事,变成一点**趣味与随机性**。相关:[模型](../../shared/concepts/models.md) · [建 bot 与预设](create-bot-presets.md)。

**逻辑**

- **会话抽一个模型,藏名让你猜**。新会话从 bot 的模型池里随机抽一个模型当「当前模型」,会话级的模型 pill 显示 `PendingModel`(配个盲盒图标),不露真名。
- **抽定即固定**(关键约束):会话当前模型一旦抽定就**固定、逐轮复用**,普通往返**永不**换。只有两件事会重抽:① 手动「重新生成」(且 bot 开了 regen 重抽,默认开);② 手动换模型(随机重抽 / 选具体模型)。
- **猜 / 揭晓的对象 = 整个会话的当前模型**(单个,不是某一条气泡)。输入框 `+` 菜单出「猜模型」:从模型列表里选一个猜,或点「不想猜(直接揭晓)」。揭晓后 pill 翻成真名,结果显示「✓ 猜对了」/「✗ 你猜的是 X,实际是 Y」/「(揭晓)实际是 Y」。
- **重抽 → 重新藏**:regen 重抽 / 换随机模型 → 新模型、揭示状态重置 → pill 变回 `PendingModel`,要重新猜。手动选**具体**模型 → 直接算已揭示(自己选的,不必猜)。
- **bot 可主动发起猜**:对话中 bot 能调一个工具,在时间线里插一张可交互的「猜一猜」卡片,你直接在卡片上作答;卡片状态持久(进历史)。
- **bot 设置两档**:
  - **保留惊喜(surprise,默认)** —— 藏名让猜。
  - **直接披露(disclose)** —— 不让猜,pill 直接显示真名,「猜模型」入口不出现。

**为什么** — 这块原来是 **arena**:LMArena 式的模型评测框架(随机抽 + A/B 盲投 + Bradley-Terry 个人排行榜)。用户要把它**从「评价」转向「娱乐」**——做成开盲盒:模型随机、藏名、让人猜,主打趣味而非评测。旧评测框架(A/B 盲投 + 排行榜)连根拔掉。

「抽定即固定」是硬约束,不是产品偏好:prompt caching 要求会话内模型稳定,否则缓存全不命中、账单爆炸。所以会话模型一抽定就锁住,只有显式 regen / 换模型才动。

**用在哪·长什么样**

- **会话级模型 pill**:未揭示显 `PendingModel`,揭示后显真名。点 pill 也能进换模型。
- **输入框 `+` 菜单**:「猜模型」(仅惊喜模式 + 未揭示时出现)+「换模型」(随机重抽 / 选具体)。
- **猜模型 sheet**:复用模型列表选一个,顶部 / 底部有「不想猜(直接揭晓)」。
- **「猜一猜」卡片**:bot 主动发起时,时间线里的可交互卡片,作答后定格为结果。
- **bot 设置**:模型身份(惊喜 / 披露)+ 重新生成时重抽 / 保持当前,两个开关;模型池编辑器(决定盒里有哪些模型)沿用。

**示例** — 你新开一个跟「老张」bot 的会话,顶上 pill 写着 `PendingModel`。聊了几句,你好奇这是哪个模型,点 `+` →「猜模型」→ 选「Claude Opus」→ 揭晓「✗ 你猜的是 Claude Opus,实际是 Gemini Flash」,pill 翻成真名。后来你对某条回复不满意,点「重新生成」——bot 重抽了一个新模型,pill 又变回 `PendingModel`,这一轮你可以重新猜。

**边界(本期明确不做)**

- 不做模型图鉴 / 收藏册、全局排行榜、跨会话统计。**纯娱乐**。
- 不画逐气泡的模型徽标——只认「当前模型」这一个会话级 pill,所以不存在「停在没猜的旧气泡」问题(历史归属仍由消息行如实记录)。

**注意**

- **arena 已退役**:A/B 盲投对比、Bradley-Terry 个人排行榜、相关的对比表和「我」页排行榜区**全删**。保留的只有「模型池随机选」(盲盒的内核)。内部个别中性命名(如模型池)沿用不强改,但任何「arena 评测 / 排行榜 / A-B 投票」的旧描述都已失效——以盲盒为准。
- **持久猜测记录有尾巴**:猜测结果在「猜的当下」显示对 / 错;重开会话目前只见真名,不见「你当时猜了 X、对 / 错」的回放(记录表已落库,但 UI 回放未补全)。见 tech-debt。
