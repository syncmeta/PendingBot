# 网上冲浪

bot 不只在对话框里等你提问——它会**自己出门上网**,找对你有价值的信息带回来。两种形态:聊天里现查现答(回话时顺手搜 / 抓网页),以及更重的"主动探索一圈、写成一篇带回来"——后者的成品就落在 [来信](envelope-inbox.md) 里。相关:[主动性](../concepts/proactivity.md) · [来信](envelope-inbox.md) · [主动复盘](proactive-lookback.md)。

**逻辑**

- **两种上网形态**:
  - **聊天里现查**(in-chat)——bot 回你话时,如果需要外部信息,自己调起网页搜索 / 抓取网页,把结果融进这一轮回复。是同步的、当场发生的,你看到回复里带着它刚查到的东西(以及它搜了什么的提示)。
  - **主动探索 + 写信**(envelope 探索相)——bot 以"写给你"的身份,读你俩跨会话的聊天,**规划一串搜索 → 抓网页 → 记笔记**,自己判断什么时候探索够了、转入写作,最后产出一篇文章放进来信 tab。这一形态的"冲浪"是它出门探索的那一段过程,产物归 [来信](envelope-inbox.md)。
- **是 bot 自己决定查什么、查到够不够**。不是你给关键词它去搜;探索相里它围绕"你的需要 / 盲区 / 值得展开的方向"自己定查询计划、自己决定何时收手。
- **挑值得讲的带回**。查到一堆不等于全倒给你——它筛出对你有价值的,空手而归(没查到值得说的)就不硬凑。
- **手动触发**:你可以手动让 bot 出去冲一圈(触发一次"主动探索 + 写信"),不必等它自动到点。(项目愿景里把这个手动入口记作 `/surf`;当前实际触发走来信探索管线,`/surf` 这个 slash 命令本身在代码里尚未单独连出。)

**为什么** — 网上冲浪是大绿豆"破信息茧房"愿景目前唯一落地的一小角雏形,衡量它的尺子是**能不能给你真价值**,不是"它有多主动"。一个真朋友给你的价值,常来自他替你留意了你没开口问、却真用得上的东西。把"上网带回有价值信息"做成 bot 自发的行为(而不仅是你点一下"联网搜索"),它才能帮你看见茧房外的东西、给真价值,而不是当个搜索引擎前端。

**用在哪·长什么样**

- **聊天里现查**:在任意会话里,bot 回复时按需自动联网;界面上会显示它搜了什么 / 抓了哪页(搜索 chip + 引用),结果直接写进回复。是否开启、用哪个搜索引擎、每次取几条等,**每个 bot 可在设置 / board 里配**。
- **主动探索 + 写信**:成品落 [来信](envelope-inbox.md) tab,详情页能展开看它一路怎么搜、怎么想的思考链。可手动触发一次探索(等同手动催一封来信;愿景里记作 `/surf`)。
- 联网搜索 / 抓网页的供应商对用户**不可见也不可配**——统一走托管服务(MCP → Exa),你只管结果。

**示例** — 你在跟 bot 聊一个刚听说的开源项目,问它靠不靠谱。它没有干答,而是当场上网搜了这个项目的最近动态、抓了仓库主页,回复里带回"最近一次发布是上个月、issue 响应挺快、不过文档偏薄"——这是**聊天里现查**。过两天它自己出门冲浪了一圈,读了你俩这阵子聊的技术选型,查了几个同类项目对比,写成一封《三个候选库,我替你比了一遍》放进来信——这是**主动探索 + 写信**。

**边界**

- **冲浪不是"代你操作网页"**。它做的是搜索 + 读取 + 提炼,不替你登录、下单、提交表单这类带副作用的动作。
- **探索相的产物归来信,不是聊天消息**——主动探索写出来的东西是一篇文章(进来信 tab),不会以聊天气泡的形式塞进会话流。
- **不保证每次都有产出**。没查到值得说的(或素材不足),这次就静默不出——来信 tab 不留"这次没写"的占位。

**注意 — 命名变迁,别被旧概念带跑**

- **"网上冲浪"在产品里的落地形态,主体是来信(envelope)**。这个能力内部早期是独立的 **scroll(奏折)→ surf** 两个 feature,后来**合并并重命名为 envelope / 来信**。所以:
  - ❌ **`surf_runs` / `scroll_runs` 表**已是**死表**(envelope 取代后无人引用,仅 schema 残留),不是活 feature 的数据源——别照着它们去想象 surf 的实现。
  - ❌ 把"网上冲浪"当成一个**独立于来信的 tab / 独立运行体**也是旧心智——它的成品就在来信里。
- **`surf` 这个会话类型名仍在枚举里保留**(单 owner 会话类型之一),但**没有对应的运行体**——属于预留 / 历史残留,不代表有一条活的 "surf 会话" 管线。拿不准时以"现查走 in-chat、探索走 envelope"为准。
- 这篇文件刻意只讲"bot 出门上网"这件**能力**;它怎么写信、来信 tab 长什么样,归 [来信](envelope-inbox.md),不在这里重复。
