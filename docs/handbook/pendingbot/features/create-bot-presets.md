# 建 bot 与模型预设

新建机器人收敛成**一页**:起个名字、勾几个**模型预设**(可加自定义)、选公开程度、创建。预设由 board 管规则、对话时动态解析,所以「头两家旗舰」这种集合会随模型市场自动更新。相关:[模型](../../shared/concepts/models.md) · [模型盲盒](model-blindbox.md) · [bot 可见性](../concepts/bot-visibility.md) · [bot 邀请](bot-invites.md)。

**逻辑**

- **一页式建 bot**(取消「下一步」两步式):一个表单里搞定——
  1. **名字** —— 默认从全世界地名(GeoNames)随机取一个,「换一个」按钮 reshuffle,也可手改。名字可改、**不要求唯一**。
  2. **模型预设 · 多选** —— 几个 board 管理的预设(默认勾前三),点行能展开看每个预设包含哪些模型。
  3. **自定义** —— 一行入口,以当前所选预设的并集为起点,进选模型页手动增删 / 筛选。
  4. **公开程度** —— 私有(默认)/ 公有·邀请制,第一屏就选,无「下一步」。
  5. **创建** —— 右上角。
- **预设 = 活的查询,不是写死的清单**。每个预设由一条**规则**驱动,对话时基于实时模型目录在内存里算出来,所以预设在 board 改了规则、已建的 bot 会自动跟随。五个预设全规则驱动,无手钉:
  - **头两家旗舰** —— 固定 OpenAI + Anthropic(board 可改),各取一个旗舰。
  - **中国旗舰** —— 中国厂白名单(deepseek / qwen / moonshot / z-ai / minimax),各取一个旗舰。
  - **各家最新** —— 按发布时间,各厂取最新一个。
  - **速度快** —— 在有质量下限的候选里,按实测吞吐取前几名。
  - **最热门** —— 按 LMArena 评分代理取前几名。
- **旗舰策略**:每厂取一个,默认「系列内最新(latest_in_series)」——锚定产品线前缀(如 claude-opus / gpt-5),系列内取发布日最新,从而选出真旗舰(opus / gpt 最新款)而不是某个旧的高价款。
- **bot 存预设引用,对话时解析**。预设驱动的 bot 存的是「选了哪几个预设」;对话 / 盲盒抽模型时把预设展开成模型并集再选。**自定义** bot 则存一份显式的冻结清单——一个 bot 要么「预设驱动(活的)」、要么「自定义(冻结)」,二选一。

**为什么** — 旧建 bot 是两步式 sheet,进页要同步拉全量模型目录(1–2MB)、主线程排几百个模型 → 「等好几秒」。新流程第一屏只拉轻量预设载荷(几个预设、几十个模型名)秒开,全量目录只在点「自定义」时才懒加载。预设规则化 + 对话时解析,让「头两家旗舰」永远指向当下真旗舰,不必人工维护清单。

**用在哪·长什么样**

- **新建机器人 sheet**(单页 Form):名字 + dice 换名 → 预设多选行(勾选框 + 标题 + 副标题列几个模型名 + 展开看完整清单)→ 自定义入口 → 公开程度 radio → 右上「创建」。
- **board**:模型预设管理页(规则下拉 + 参数 JSON 编辑),运营在这里增删 / 调预设,改动数秒内全球生效。

**示例** — 你点「新建机器人」,名字栏自动填了「Casablanca」,你嫌不顺手点「换一个」变成「Kyoto」。预设默认勾了「头两家旗舰 / 中国旗舰 / 各家最新」前三,你点开「头两家旗舰」看到当下是 GPT-5.5 + Opus 4.8。你不想自定义,公开程度留默认私有,点「创建」——一个叫 Kyoto、模型池跟着这三个预设走的私有 bot 就建好了。日后 board 把旗舰策略一改,这个 bot 抽到的模型自动跟新。

**边界**

- 不做「性价比」预设(用户明确先不要)。
- 不改盲盒抽模型 / 揭示机制本身——只是把「模型池的来源」换成预设引用。
- 不引入新计费 / 可见性档位。

**注意**

- **vanity slug 彻底退役**。bot 现在是**显示名(可改、不唯一)+ 自动生成 id(唯一、不可改、链接用)**,和人类账号一致;创建 / 管理全程**不让用户碰 slug**。早期「保留 slug 当展示 @名」的说法也随这次退役一并取消——**slug 不再是产品里的概念**。分享 / 深链用自动 id,不受影响(见 [bot 邀请](bot-invites.md))。
- **默认私有**(从早期某版的默认公有改回)——规避「公有永久不可逆」的坑。配套放宽:公有 bot 若**只有创建者一人是好友**(无其他采用者)仍可删。
- **数据源实测纠偏**(写实现时务必照现状):OpenRouter 稳定版 `/api/v1/models` 的 `order=` 排序参数**实测完全无效**(前端专用),前端 / rankings 端点全 404,edge 里也没有 OpenRouter key。所以「速度快」改走 per-model endpoints 实测吞吐,「最热门」改用 LMArena 评分代理(= 评测质量榜,**不是真实使用量榜**,已接受)。
- **「最贵」旗舰策略已弃用**:`most_expensive` 实测会选到旧款(混合成本估算把旧高价款排前),已改默认 `latest_in_series`。
