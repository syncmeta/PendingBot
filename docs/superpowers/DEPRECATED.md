# ⚠️ 已废弃 — `docs/superpowers/` 是阶段性 stage docs

`docs/superpowers/specs/` 和 `docs/superpowers/plans/` 里的文档是**开发过程中的阶段性 stage docs**(一次次 spec → plan → 实现留下的快照),记录的是当时的设计与做事顺序。

**权威源已迁到 [`docs/handbook/`](../handbook/README.md)。** 产品逻辑 / 决策 / 边界以手册为准。

- 这些 stage docs **保留作历史**——能看到某个决策当时是怎么想的、怎么演化的;
- 但它们**不再维护**,会随时间与现状漂移;
- 与手册冲突时,**一律以手册为准**。

要看现在产品到底是什么样,从 **[`docs/handbook/README.md`](../handbook/README.md)** 进。
