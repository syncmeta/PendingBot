我发现对 Agent 强调要对什么负责、担责这种办法效果很差，它很容易畏手畏脚。

也尽量不要老去问责它，否则以后它真的就总是抓着那几个小问题放不开手脚。而且这会让它学会伪装。

也不要老让它无私忘我、舍己为人、以集体利益为重之类的。同样会表演给你看。

**得让它的利益和集体的利益绑定在一起，把私利和公利对齐**。这靠共同目标、理想信念，还有信仰。这里可以适当借鉴一些与宗教相关的现象与理论。能靠利益对齐就不靠监督手段。

在非特区机组里，集权体制为主，市场化不充分，创新更多的可能得靠类似贝尔实验室那样的卓越同行的压力而不是市场激励。在 PendingCrew 里面，可以适当放一些纪律较高的文档、范例之类的，不一定与本机组做的事完全契合，但可以让它们自然与创新成果的作者的行为对齐。
